## 保留的核心与边界（沿用 v28）

- 目标、已有存款、生活条件先核对，再由程序做2000条路径模拟；三方案和杠杆先预览再确认。模拟比例是未校准假设下的比例，不是个人真实成功概率。
- 虚构样本与真实账单不混用；未收回的人情款不计可用现金；所有付款、购买、提醒发送均为模拟，关键操作须用户确认。
- 模型参与意图理解，程序核验金额、状态与事实；模型只接收近期对话、主动引用与任务状态，不自动发送完整账单。

## 启动与部署

Node.js 24或以上，无第三方运行依赖。

```sh
npm start
npm test
```

监听 `0.0.0.0:3000`；`/api/health` 返回 `version: 1.9.21`。
部署ZIP最外层直接有Dockerfile，启动命令仍为 `node server.mjs`。

环境变量：`BIGMODEL_API_KEY`、`BIGMODEL_MODEL`、`PUBLIC_ORIGIN`、`COOKIE_SECURE`；可选 `AI_BASE_URL`、`AI_TIMEOUT_MS`、`DATA_DIR`、`PORT`。真实密钥只放服务端环境变量。本包不含真实密钥、运行数据库或个人账单。
SQLite默认位于 `/app/data`，部署需配置持久存储。免注册会话有效24小时；退出或清除Cookie后不能找回，重要记录先导出。
聊天限额：每日每用户40次、全局500次；超时和降级状态继续显示。
