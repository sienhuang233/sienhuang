# 钱程 v59

**在线体验：[打开钱程](https://en-327891-12-1505581441.sh.run.tcloudbase.com/)**　｜　程序版本：1.9.45

钱程面向大学生与初入职场年轻人，通过自然语言对话，把储蓄愿望、消费线索和人情往来连接成可核对的资金计划。系统如实告知目标可行性，并帮助用户比较调整条件后的变化。

**本项目是银行 AI 智能体沙箱原型，无真实银行转账、平台退订、理财交易或消息发送。**

## 推荐体验路径

**建议使用电脑浏览器体验。** 本作品以电脑端为主要体验方式，手机端布局与交互体验有限。点击“免注册开始”，使用虚构案例。

**快速体验：先完成第1、2步；查看跨场景联动，再继续第3、4步。**

若云端实例正在启动或从休眠恢复，首次访问可能需要等待；页面暂未响应时，请稍后刷新。

| 步骤 | 操作 | 观察重点 |
| --- | --- | --- |
| 1. 说出愿望 | 输入“我想攒钱”，再答“5000元六个月” | 补问缺项、接续上下文 |
| 2. 比较方案 | 选择虚构学生情形，核对条件并计算 | 比较三种方案，预览后确认 |
| 3. 体检账单 | 分析虚构账单，核对订阅或预览预算调整 | 依据来自账单，采纳由用户决定 |
| 4. 核对往来 | 核对100元转账用途，体验提醒与模拟归还 | 不重复扣款，保留未结清金额 |

需要继续时可使用“钱程推荐下一步”。关键操作在页面确认；普通“好”“继续”不代替保存或付款确认。订阅取消只记录模拟状态，真实续费仍需到原平台关闭。

## 核心功能与 Agent 分工

- **目标教练**：对话收集金额、期限与现实条件，程序以每组2000条路径比较冲刺、均衡、宽松三种储蓄节奏，形成执行安排。
- **账单体检**：支持账单导入、消费分类、订阅及疑似重复扣费线索核对；用户确认的预算行动可反馈到目标计划。
- **人情往来**：支持垫付、借入/借出、AA、日期性质、部分/全部归还与模拟提醒，避免重复形成现金流。

模型辅助理解意图、提取有原话依据的字段，并参与订阅优先项判断及解释；任务状态与规则决定缺项和下一步，程序负责计算、草案及记账。执行结果再更新页面和推荐。模型没有直接写入账本的权限。

## 本地运行与测试

需要 **Node.js 24或以上**。运行代码无第三方 npm 依赖，在解压后的项目根目录启动：

```bash
npm start
```

打开 http://localhost:3000 。访问 `/api/health` 可核对 `version: 1.9.45`、`bank: sandbox`。

另开终端，在同一项目目录执行测试：

```bash
npm test
```

**v59共158项自动测试通过。** 测试覆盖范围与详细结果见技术文档及安全自评报告。

## 模型配置与部署

本地可在项目根目录的 `.env` 中配置，修改后重启；CloudBase在平台环境变量中配置，更新后重新部署。

| 环境变量 | 用途与填写方式 |
| --- | --- |
| `BIGMODEL_API_KEY` | 接入模型时必填，填写服务端模型密钥 |
| `BIGMODEL_MODEL` | 接入模型时必填，填写密钥有权限调用的模型ID |
| `AI_BASE_URL` | 可选；默认 `https://open.bigmodel.cn/api/paas/v4/chat/completions` |
| `AI_TIMEOUT_MS` | 可选；默认18000毫秒 |
| `PUBLIC_ORIGIN` | 云端填写实际HTTPS访问来源，不带路径或末尾斜杠 |
| `COOKIE_SECURE` | 公开HTTPS部署填写 `1` |
| `DATA_DIR` | SQLite数据目录；容器默认 `/app/data`，需在平台确认持久化挂载 |
| `PORT` | 服务端口，默认 `3000` |

未配置模型时使用规则模式；模型失败或额度耗尽时显示相应状态并尽可能由规则续接。界面“模型已配置”仅表示已读到配置，是否成功以本次回复状态为准。模型调用尝试额度为每账户每日40次、全站每日500次；基础请求限流独立保留。

CloudBase使用根目录Dockerfile构建，服务端口3000。详细步骤见[部署说明](DEPLOYMENT.md)。不要将 `.env`、密钥、个人账单或运行数据库加入提交包。

## 已知边界

- **模拟比例未经真实用户数据校准**，不能当作个人未来成功概率；预算调整是执行假设，不是已经省下的钱。
- **“每月多存500元”敏感度卡片与实际预览在部分条件下口径不一致**，尚未修复，不能将卡片数值直接当作已验证的改善。
- **游客高风险体验受限**：当日已模拟出账加本次金额超过1000元、模拟申购等操作需要验证器动态码。游客目前无法完成绑定所需的账户密码复核，相关操作不会执行，权限政策待完善。
- 升级前已混合的真实/模拟历史不自动重建，旧报告快照不自动重写；可经原分析入口更新。SQLite持久化与单实例部署需实际核验，未实现多实例共享存储。
- 真实模型效果、手机端体验及容器和云端运行需在相应环境单独验收。
